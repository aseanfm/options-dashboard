# 全球指数期权 T 型报价

三级标签看板：**A股 / 港股 / 美股**（最高级）→ 各标的 → 各产品类型。

- A股：510050 上证50 / 510300 沪深300 / 510500 中证500 / 159901 深证100 / 159915 创业板 / 588000 科创50 的 ETF 期权
- 港股：恒生指数 / 恒生中国企业指数 / 恒生科技指数 × 指数期权（现金交割）/ 期货期权 / ETF期权
- 美股：S&P 500 / Nasdaq 100 / Russell 2000 × ETF期权（SPY/QQQ/IWM，实物）/ 指数期权（SPX/NDX/RUT，现金）/ 期货期权（ES/NQ/RTY）

栏目：最新价、买/卖、隐含波动率、持仓量、维持保证金（估算）、折算年化、在值程度 M、合成远期 F。

## 自动更新

GitHub Actions 每个交易日（周一至周五）北京时间 **10:00** 和 **13:30** 自动抓取行情并重建本页，
提交回仓库后 GitHub Pages 自动发布。历史快照见 git 提交记录。

## 数据源

- A股：东方财富 push2 实时行情
- 港股：港交所官网行情组件（免费延迟行情）
- 美股 ETF/指数期权：CBOE 官方延迟报价（约15分钟，含 IV）
- 美股期货期权：`cme_data.json`（CME 官网延迟行情，仅平值附近±10档、无盘口/持仓，
  因 CME 接口需浏览器渲染，此文件为手工转录，需定期更新；缺失时对应子标签显示"暂无数据"）

## 文件说明

- `fetch_build.py` — 编排脚本：A股 → 港股 → 美股 → 重建页面（`pip install requests && python3 fetch_build.py`）
- `build_dashboard.py` / `dashboard.css` — 建站与样式（三级 Tab）
- `hk_fetch.py` / `hk_render.py` — 港股抓数 / 渲染
- `us_fetch.py` / `us_render.py` / `cme_data.json` — 美股抓数 / 渲染 / CME期货期权数据
- `data/secids_{代码}.txt` — 各A股标的期权合约的东财 secid 列表（逗号分隔）
- `.github/workflows/daily.yml` — 定时工作流

## 合约列表维护

`data/secids_*.txt` 是某日的合约全集。每月第 4 个周三到期日后、或标的大幅波动加挂新行权价时，
需要刷新列表（新合约代码可从行情软件的期权链导出，按 `10.`（沪市）/`12.`（深市）前缀 + 代码 的格式追加分块即可）。
美股/港股合约由抓取脚本自动生成，无需维护。
